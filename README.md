# FitSync
Workout application
people start working out using random plans from the internet or apps, which are not tailored to their body type, fitness level, or goals. This often leads to slow progress, injuries, or loss of motivation. Beginners especially struggle to decide what exercises to do, how many sets/reps, and how to progress over time.
our project aims to develop a smart workout application that provides personalized workout plans, tracks user progress, helps maintain consistency through reminders and insights and provide guidance
